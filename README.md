# waretrack-3d

A clean-room, from-scratch re-implementation of the idea behind **[nguyenthong251/waretrack-3d](https://github.com/nguyenthong251/waretrack-3d)** by [@nguyenthong251](https://github.com/nguyenthong251). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
